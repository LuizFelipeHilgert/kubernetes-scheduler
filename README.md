# Kubernetes Custom Scheduler

## Projeto da disciplina — Scheduler Customizado com Kubernetes

Este projeto apresenta a implementação de um scheduler customizado desenvolvido em Python para simular o escalonamento de pods em um cluster Kubernetes local.

O ambiente foi executado utilizando **Kind**, **Kubernetes**, **Docker Desktop** e **Python 3**.

---

# Tecnologias utilizadas

- Kubernetes
- Kind
- Docker Desktop
- Python 3
- kubectl
